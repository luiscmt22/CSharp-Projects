The split

Your _Organized folder is excellent conceptual material — it explains how things work. It has zero exercises. These drills are the missing half: they make you write code from a blank file using those concepts. Read the guide, then drill it. Drill it, then re-read the guide. The two reinforce each other.

The criterion for inclusion: would mastering this make you feel like a programmer who happens to use C# rather than someone who can fix C# code with help? If yes, it's on the list.

Status & pace

Realistic pace from me: 1–2 high-quality drill docs per session. Each doc is 15–25 drills, hand-written hints, no padding. Rushing them defeats the point — weak hints would tempt you to ask me to solve drills, which is exactly the trap we're avoiding.

Your pace: 3–5 drills per sitting, ideally daily for two weeks per topic. That's how the blank-page reflex actually rebuilds.

Suggested order

All twelve drill docs are now written. I'd recommend this order based on dependency — each builds on the previous:

Foundation (do these first)

Everything else assumes you can do these in your sleep.

  1. Collections & Equality (done) — data structures + the contract that makes them work
  2. LINQ (now) — data manipulation reflex
  3. Value vs reference types (planned, read CSharp_Stack_and_Heap_Guide first)

Modern C# style (do these next)

What makes 2025 C# different from 2015 C#. These are what employers look at.

  1. Pattern matching, records, value objects
  2. Delegates, lambdas, Func/Action (skip if you feel solid — you use them daily)
  3. Async & await (now) — non-negotiable for any modern .NET work

Robust code (do these after the above)

The difference between code that works and code that stays working.

  1. Exception handling
  2. Generics (read CSharp_Generics_Guide first)
  3. Strings & formatting

Design intuition (last)

Once the language is reflexive, work on how to shape code.

  1. Enums & Flags (read 12-CSharp-Flags-Enum first)
  2. Design pattern micro-drills (Strategy, Adapter, Chain of Responsibility)
  3. Builder pattern exercises (done — in C1/docs/)

When you're ready for more

The 12 docs are complete. Total: ~200 drills. At 3/day that's roughly 9 weeks of practice. If after working through them you want sibling docs on adjacent topics, ask:

  • Observer / events — pub/sub pattern as a primitive.
  • IAsyncEnumerable & channels — streaming async data.
  • Reflection & attributes — reading types at runtime.
  • EF Core query patterns — the right time is when LINQ is reflex.
  • Blazor component patterns — when async and DI are reflex.

Don't try to do them all at once. The reps need spacing to stick. Three drills a day for two weeks beats 30 drills in one weekend — the brain consolidates motor patterns during sleep, not during a marathon. Pick one topic, work it daily, move on when each drill feels “trivial” rather than “done”.
